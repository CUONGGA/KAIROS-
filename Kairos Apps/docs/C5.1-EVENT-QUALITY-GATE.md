# C.5.1 Event Quality Gate

## Purpose

Protect LLM summaries from sensitive or low-value event content. This gate is applied twice: first by the
Codex collector before it persists event text, then by the Frappe server immediately before it builds an LLM
prompt.

## Server-side boundary

`kairos.quality.sanitize_event_for_llm` normalizes text, applies field bounds, and returns an explicit
eligibility decision. It redacts private-key blocks, bearer tokens, common credential assignments, URL
credentials, and absolute paths. Markup/system-context events and events that contain only redacted content
are excluded.

`kairos.summary.build_llm_safe_timeline` queries an allowlist of canonical fields only. In particular, it
does not query, deserialize, log, or send `raw_payload` to the model. The Desk Timeline remains an audit view;
the LLM and its local fallback receive the separately sanitized timeline.

## Collector boundary

The Codex mapper applies the same credential redaction to `title`, `summary`, and its debug snippet before
synchronizing an event. New collectors must provide equivalent redaction fixtures before they can contribute
to LLM summaries.

## Verification

Run the focused checks:

```bash
PYTHONPATH=src python3 -m unittest tests.test_mapper
PYTHONPATH=/path/to/Kairos\ Apps/kairos python -m unittest kairos.test_quality
```

For Frappe integration tests, enable testing only on a development site, then run
`bench --site kairos.local run-tests --app kairos --module kairos.test_summary`.
